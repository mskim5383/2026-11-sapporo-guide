# 12-feature-sake 출처 (와인·사케 기자, 2026-11-08 접속)

## 1. 国税庁(국세청) 「「清酒の製法品質表示基準」の概要」
- URL: https://www.nta.go.jp/taxes/sake/hyoji/seishu/gaiyo/02.htm (curl, Shift_JIS 로 디코드. WebFetch 는 글자 깨짐)
- 특정명칭 표(원문 그대로):
  - 吟醸酒: 米、米こうじ、醸造アルコール / 精米歩合 60%以下 / こうじ米使用割合 15%以上 / 吟醸造り、固有の香味、色沢が良好
  - 大吟醸酒: 同 / 50%以下 / 15%以上 / 吟醸造り、固有の香味、色沢が特に良好
  - 純米酒: 米、米こうじ / － / 15%以上 / 香味、色沢が良好
  - 純米吟醸酒: 米、米こうじ / 60%以下 / 15%以上
  - 純米大吟醸酒: 米、米こうじ / 50%以下 / 15%以上
  - 特別純米酒: 米、米こうじ / 60%以下又は特別な製造方法（要説明表示）/ 15%以上
  - 本醸造酒: 米、米こうじ、醸造アルコール / 70%以下 / 15%以上
  - 特別本醸造酒: 同 / 60%以下又は特別な製造方法（要説明表示）/ 15%以上
- 「精米歩合とは、白米のその玄米に対する重量の割合をいいます。精米歩合60%というときには、玄米の表層部を40%削り取ることをいいます。」
- 「吟醸酒や本醸造酒に使用できる醸造アルコールの量は、白米の重量の10%以下に制限されています。」
- 「吟醸造りとは、吟味して醸造することをいい、伝統的に、よりよく精米した白米を低温でゆっくり発酵させ、かすの割合を高くして、特有な芳香（吟香）を有するように醸造することをいいます。」
- 平成15年 개정(平成16年1月1日 시행): 「純米酒の製法品質の要件から「精米歩合70%以下」を削除しました。」
- 令和4年 개정(令和5年1月1日 시행): 「(3) 複合表示 「生原酒」、「生貯蔵原酒」などの表示が可能となります。」
- 任意記載事項: 「(4) 原酒 製成後、水を加えてアルコール分などを調整しない清酒に表示できます。…アルコール分1%未満の範囲内で加水調整することは、差し支えない」 / 「(5) 生酒 製成後、一切加熱処理をしない清酒に表示できます。」 / 「(1) 原料米の品種名 表示しようとする原料米の使用割合が50%を超えている場合に、使用割合と併せて、例えば、山田錦100%と表示できます。」
- 「生酒、生貯蔵酒以外の清酒は、通常、製成後、貯蔵する前と出荷する前の2回加熱処理をしています。」
- 「清酒（原料の米に国内産米のみを使い、かつ、日本国内で製造された清酒に限り「日本酒」と表示してもよいことになっています。）」
- ひやおろし·しぼりたて·新酒 는 이 기준에 정의가 없다(문자열 0건). 日本酒造組合中央会(japansake.or.jp)는 WebFetch·curl·내장 브라우저 모두 인증서 오류로 열리지 않아, BRIEF 3-3 확인할 것 ②에 따라 정의 없이 "계절의 말"로만 썼다.
